# Body Model Specification v0.1

## 기본 원칙
- H = 머리 높이(두개골 상단~턱끝).
- 키는 절대 Lock.
- 등신이 머리 크기를 결정한다: `head_height_cm = height_cm / head_count`.
- 체중은 초기 Body Volume 추정값에 사용한다.
- 체중만으로 체형을 확정하지 않으며 개별 슬라이더가 최종 Body Spec을 보정한다.
- 수치는 현실 인체 평균의 의학적 표준이 아니라 프로젝트용 2D/파라메트릭 마네킹 기준값이다.

## Body Volume 기준
- 남성 175cm / 75kg = Male Body Volume 1.00.
- 여성 162cm / 55kg = Female Body Volume 1.00.
- 체중 변화는 흉곽, 허리, 골반, 팔, 허벅지, 종아리 등의 초기 볼륨에 분산 적용한다.
- 머리 크기와 총 키는 체중 변화로 변경하지 않는다.
- 정확한 체중→각 부위 변환식은 OxiHuman 모프 구조 검증 후 확정한다.

## 수동 조정
초기 후보:
- 어깨폭
- 흉곽폭
- 허리폭
- 골반폭
- 상체길이
- 다리길이
- 팔길이
- 허벅지 굵기
- 종아리 굵기

폭 계열은 우선 기본값 대비 약 ±15% 범위를 검토한다.
길이 계열은 전체 키 보존을 위해 약 ±8~10% 범위에서 상호 재분배하는 방식을 검토한다.

## 계산 우선순위
`키(절대) → 등신(머리 크기) → 성별 기본 프리셋 → 체중 기반 초기 볼륨 → 사용자 세부 보정`
