# Third-party / Licensing Plan v0.1

> 실제 배포 전에는 사용 중인 정확한 OxiHuman 버전과 포함 자산의 라이선스를 다시 확인한다.

## OxiHuman
기획 단계 기준:
- 코드: Apache License 2.0
- 기본 인체 mesh/morph 계열 자산: CC0-1.0으로 제공되는 범위를 우선 사용
- 상업/비상업 배포 여부와 관계없이 Apache-2.0 고지 의무를 준수한다.
- 배포물에 필요한 LICENSE/NOTICE 및 제3자 고지를 유지한다.

## MakeHuman
- MakeHuman 프로그램의 AGPL 코드를 본 프로젝트에 직접 포함하거나 복사하지 않는다.
- CC0로 명확하게 허용된 자산을 사용할 경우에도 출처와 정확한 라이선스를 기록한다.
- 커뮤니티/제3자 자산은 각각 별도 라이선스 검토.

## 프로젝트 관리
`licenses/`와 `THIRD_PARTY_NOTICES.md`에서 실제 사용 버전, URL, 저작권 및 라이선스 문구를 관리한다.
