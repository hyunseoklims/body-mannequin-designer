# Body Mannequin Reference v2

Body Mannequin Designer 프로젝트용 남녀 정면 레퍼런스 이미지 묶음입니다.

## Files
- `references/male-front-reference.png` — 남성 정면 레퍼런스
- `references/female-front-reference.png` — 여성 정면 레퍼런스

## Usage
- BaseProfile 제작/비교용 시각 기준
- Reference Image Mode용 이미지
- Overlay Compare에서 Generated Mannequin과 비교
- 이미지 하단 기준선을 floor/baseline 정렬 기준으로 사용

원본 비율을 유지하고, 키 비교 시 세로 스케일을 입력 height에 맞춰 적용합니다.
